# /lhg-email:subject —— 邮件标题优化

用户输入在 `$ARGUMENTS` 中：`"<这封邮件想说什么>" [--lang zh|en]`。

## 流程（加载 lhg-email-copy 第 3 节全程指导）

### 1. 先定邮件类型
- 促销型（给优惠）→ 用「利益前置」公式
- 内容型（给干货）→ 用「好奇缺口」公式
- 事务型（订单/物流）→ 用「清晰直给」公式，别玩花样

### 2. 生成 3 备选
每套公式出 1 个，共 3 个标题 + 每个配 1 句预览文本（preview text）。
标注每个标题的预期作用（提打开率 / 提点击 / 保送达）。

### 3. 三项硬检（不过就改）
1. **长度**：英文 ≤ 50 字符 / 中文 ≤ 20 字（含空格），移动端标题栏只能显示这么多
2. **emoji**：≤ 1 个，且不许放在开头
3. **垃圾词**：跑一遍审计脚本的垃圾词表（免费领取/一夜暴富/!!!/全大写），命中就换说法

### 4. 输出
```markdown
## 标题备选
1. <标题>（<公式名>，预期：<作用>）
   预览：<preview text>
2. ...
3. ...
推荐：<第 X 个>，理由：<一句话>
```

## 硬规则
- 标题党（标题承诺正文没有）→ 不许，打开率高一次、进垃圾箱一辈子。
- 全大写标题 → 不许，这是垃圾邮件过滤器的重点照顾对象。
- 一次只给 3 个，不要 10 个 —— 选择困难等于没选。
