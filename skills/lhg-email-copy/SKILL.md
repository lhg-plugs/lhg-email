# lhg-email-copy：邮件标题与正文撰写

> 目标：写出「愿意打开、看得下去、点了 CTA」的邮件。
> 核心纪律：**一封邮件只放一个 CTA；标题承诺正文必须兑现；移动端 3 秒能看完。**

## 1. 何时使用

- 序列蓝图已定（先过 lhg-email-sequence），开始写具体邮件 → 用本 skill
- 只想优化标题 → 看第 3 节
- 打开率高但点击率低 → 看第 4 节的 CTA 与正文结构

## 2. 输入输出

- **输入**：邮件目标（这封邮件想让用户干什么）+ 用户分层 + 语言（中/英）
- **输出**：标题（3 备选）+ 预览文本 + 正文（HTML+纯文本思路）+ CTA

## 3. 分步方法论

### 第一步：标题（三套公式，一次给 3 个备选）

**公式 A：利益前置**（促销/优惠类）
```
<具体利益> + <限制条件>
例：首单 8 折，仅限本周 / 首单立减 $10，今晚截止
```
**公式 B：好奇缺口**（内容/故事类）
```
<反常识钩子>，但不说完
例：90% 的铲屎官都喂错了猫粮 / 我们差点倒闭的那一年
```
**公式 C：清晰直给**（事务/通知类）
```
<是什么> + <要你干什么>
例：你的订单已发货，点击查物流 / 优惠码今晚过期
```

**标题三项硬检**（不过就改）：
1. 长度：英文 ≤ 50 字符 / 中文 ≤ 20 字（移动端标题栏就这么宽）
2. emoji ≤ 1 个，不许放开头
3. 不许全大写、不许 3 个以上感叹号、不许垃圾词（免费领取/一夜暴富/点击赚钱）

### 第二步：预览文本（Preview Text，别浪费）

- 预览文本是标题后面那行小字，很多人不写，等于浪费一半标题栏。
- 写法：标题没说完的话放这里（如标题「我们差点倒闭的那一年」→ 预览「后来靠一款猫粮活过来了」）；促销类放关键限制（「优惠码：WELCOME10」）。
- 长度：40~90 字符，太长了显示不完。

### 第三步：正文结构（5 段式，移动端优先）

```
1. 称呼+一句话钩子（3 秒内让人知道"这封邮件跟我有什么关系"）
2. 一个故事/一个痛点（100 字以内，别写小作文）
3. 转折：所以我们做了 X（产品/优惠/内容出现，只出现一次）
4. CTA 按钮（全邮件唯一，动词开头：去看看 / 领取优惠 / 立即购买）
5. P.S. 一行（很多人直接拉到最后看 P.S.，把最重要的再说一遍）
```

**正文 checklist**：
- [ ] 段落 ≤ 3 行，手机上不翻两屏
- [ ] 图片有 alt 文本（图片被屏蔽时还能看懂）
- [ ] 链接都带 utm 参数（`?utm_source=newsletter&utm_medium=email&utm_campaign=<名称>`）
- [ ] 纯文本版同步写一份（HTML 被拒收时还有退路）
- [ ] 退订链接在底部，一眼能找到（合规红线，见 lhg-email-deliver）

### 第四步：CTA（一封邮件只放一个）

- 动词开头 + 具体利益：「领取 10% 优惠」好过「点击这里」。
- 按钮在首屏就能看到（别让用户翻三屏才找到）。
- 转化类邮件 CTA 出现 2 次（首屏一次、P.S. 前一次），但**是同一个 CTA**，不是两个不同的。

### 第五步：写完自查三问

1. **标题党了吗**：标题承诺的，正文前三行有没有兑现？没有 → 改标题。
2. **能 3 秒看完吗**：手机上滑一下，能不能抓住核心信息？不能 → 砍字。
3. **我想点吗**：把自己当收件人，CTA 有没有点的冲动？没有 → 回到第一步重想利益点。

## 4. 中英文差异（出海注意）

| | 中文邮件 | 英文邮件 |
|---|---|---|
| 称呼 | 亲爱的+名字/昵称 | Hi + First Name（拿不到名就别硬称呼） |
| 语气 | 可以更亲近、口语化 | 保持简洁直接，少用感叹号 |
| 长度 | 可以稍长（中文信息密度高） | 越短越好，150 词以内最佳 |
| 促销表达 | 「限时」「最后 X 件」有效 | 同样有效，但别堆叠（urgency  fatigue） |
| 合规 | 退订链接必须有 | 退订链接 + 物理地址（CAN-SPAM 要求） |

## 7. A/B 测试（别拍脑袋，用数据说话）

- **一次只测一个变量**：标题 A/B 就只换标题，正文、CTA、发送时间全保持一致。
- **样本量**：每组至少 1000 人再看结论，200 人的"胜利"大概率是噪音。
- **测试顺序**：先测标题（影响打开率，杠杆最大）→ 再测 CTA（影响点击）→ 最后测正文长度。
- **测试节奏**：每周测 1 个变量，测完把赢家固化成默认，再测下一个。
- **记录**：每次测试记"假设→变量→结果→结论"，攒 3 个月就是你的专属 playbook。

## 8. 高频场景示例（照着改）

### 欢迎序列第 1 封（英文电商）

```
Subject: Welcome in — here's 10% off your first order
Preview: Code WELCOME10, valid this week

Hi there,

Welcome to <店名>! We're a small team obsessed with <品类>.

Here's 10% off your first order: WELCOME10
[Claim 10% off]

P.S. It expires Sunday — don't let it gather dust.

<退订链接> | <店名>, <物理地址>
```

### 加购挽回第 1 封

```
Subject: Forgot something? Your cart is waiting
Preview: Still available — checkout in 1 minute

Hi <名>,

You left <商品名> in your cart. It's still here waiting for you.
[Complete checkout]

Questions? Just reply — a human reads every email.

P.S. Free returns within 30 days, no questions asked.
```

**用示例的方法**：结构照抄（标题公式/5 段式/CTA 位置），内容按你的产品重写 —— 不要只换个店名就发。

## 9. 反模式（不要这么干）

- ❌ 标题「你中奖了！！！」正文是促销 —— 标题党，投诉率爆炸
- ❌ 一封邮件 5 个 CTA（买这个/看看那个/关注我们/转发朋友）—— 等于没有 CTA
- ❌ 纯图片邮件（整封就一张大图）—— 图片被屏蔽=空白邮件，还容易进垃圾箱
- ❌ 正文 800 字小作文 —— 没人看，砍到 200 字以内
- ❌ 链接裸奔（无 utm）—— 发了多少、点了多少全靠猜
- ❌ 没有纯文本版 —— 某些企业邮箱直接拒收纯 HTML 邮件
- ❌ 退订链接藏在小字里找不着 —— 用户找不到退订就会点「举报垃圾邮件」，更惨

## 6. 自检与反馈

每次用完本 skill，做一次轻量自检：

1. 标题 3 备选给了吗？三项硬检过了吗？
2. 预览文本写了吗？（别空着）
3. 正文 5 段式走完了吗？CTA 唯一吗？
4. 退订链接、utm 参数、纯文本版三件套齐了吗？
5. 自查三问（标题党/3 秒/想点）过了吗？

标准冒烟用例：给「欢迎序列第 1 封」写完整邮件（含 3 个标题备选），检查公式、三项硬检、三件套是否齐全。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-email/issues，正文写清「输入 → 错误输出 → 期望输出」。
